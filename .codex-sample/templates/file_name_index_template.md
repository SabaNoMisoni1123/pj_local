# ファイル名インデックス

目的: ファイル名・パス・メタデータだけで、AIエージェントが読む候補を絞るための仮索引。未読ファイルの内容は断定しない。

記入方針: 全ファイルを載せる必要はない。読む/除外する判断に効くファイルとフォルダだけ記録する。
