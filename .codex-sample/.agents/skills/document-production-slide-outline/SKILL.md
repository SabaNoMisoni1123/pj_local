# Document Production Slide Outline

## Purpose

Define audience, storyline, key messages, evidence, and exhibits before slide production.

## Workflow

1. Confirm purpose, audience, use setting, length, format, and delivery constraints.
2. Identify the overall message, desired audience action, and non-negotiable points.
3. Build the storyline from context to findings, implications, recommendations, and next steps.
4. Use one primary message per slide.
5. For each slide, specify title, message, content, exhibit idea, evidence, and open issues.
6. Check duplication, missing transitions, unsupported claims, and excessive detail; suggest appendix pages when useful.

## Output

Use Japanese unless requested otherwise. Recommended sections:

- 資料目的
- 想定読者・利用場面
- 全体メッセージ
- 構成案
- スライド別アウトライン
- 図表・ビジュアル案
- 必要な根拠・素材
- 未確定事項
- 次の作業

Slide tables should use `ページ`, `章`, `タイトル`, `キーメッセージ`, `掲載内容`, `図表案`, `根拠・出所`, `要確認`.

## Quality Checks

- Prefer message-oriented slide titles where appropriate.
- Avoid decorative visuals that do not help understanding.
- Mark speculative recommendations and missing data clearly.
- Use markitdown-mcp only when non-text decks or files must be inspected; note layout, chart, and notes conversion limits.
- Follow active `AGENTS.md` and `operating_ja/`; do not store project-specific facts in this skill.
