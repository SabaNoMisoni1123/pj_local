# AGENTS.md 更新方針

## 1. 基本方針

`AGENTS.md` は強い運用ルールを持つファイルです。既存の `AGENTS.md` を自動上書きしてはいけません。

## 2. 更新する場合

更新が必要な場合は、まず追記案を新規ファイルとして作成します。

推奨名:

```text
AGENTS_update_codex.md
codex_agents_update_proposal_{YYYYMMDD}.md
```

## 3. 追記案に含めるもの

- 追加したいルール
- 追加理由
- 影響範囲
- 既存ルールとの関係
- 既存ルールと矛盾しないことの確認

## 4. 禁止事項

- 明示承認なしに既存 `AGENTS.md` を上書きしない。
- 既存ルールを削除しない。
- 共通ルールを案件固有の事実で汚染しない。
